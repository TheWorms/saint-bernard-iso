# Saint-Bernard 2026.11.4

Released on 21 November 2026. Image: `saint-bernard-2026.11.4-068f6eb-amd64.iso` (1.1 GB).

## What's new

- **Practical sheets for the 81 essential tools** (cloning, recovery, partitions, file systems, boot, network…), on top of those for the `rescue-*` tools: 104 sheets, in French and English, opened with the tool.
- **Terminal**: administration tools (`fdisk`, `mount`, `parted`, `dmesg`…) run directly, with `sudo` added when needed. When it opens (Super+Enter), choose a user or an administrator terminal.
- **`mount` explains** why a protected disk mounts read-only and how to unlock a destination.
- **`rescue-chroot`**: enter the installed system of a disk (Btrfs and its subvolumes, `/boot`, `/boot/efi`) to repair GRUB or the initramfs; everything goes back to read-only on exit.
- **Wi-Fi for common PCs** (Intel, Realtek, MediaTek, Atheros, Broadcom): `rescue-net wifi`.
- The machine's **IP address** in the monitor (Conky).

## Validation

Virtual machines: BIOS and UEFI with Secure Boot boots; terminal, `rescue-chroot` and Wi-Fi test benches without failure; sheets tested tool by tool.
